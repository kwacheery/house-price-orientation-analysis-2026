## 摘要

本项目以广州二手房为研究对象，使用房天下广州深度翻页数据与链家/贝壳多城市首页数据，完成"采集 → 清洗 → 特征工程 → 房价预测 → 朝向溢价分析 → Web 可视化"全链路。原始采集 3326 条，清洗后 3302 条（建模可用 3297 条）；主分析样本为广州房天下 1251 条，按区县分层划分为训练 1000 / 测试 251。建模采用三个基线（全局均值、区县均值、面积单变量）与 Ridge、RandomForest、HistGradientBoosting 三个候选模型，最优 HistGB 测试集 RMSE 为 14106 元/㎡、R² 为 0.710，相对区县均值基线 RMSE 下降 25.8%。朝向溢价分析以"北"为参照，在控制面积、楼层、户型与区县固定效应后，朝南溢价 +4.1%（95% CI [−5.4%, +14.4%]，p=0.413），未发现显著溢价；原始朝向分布的 Kruskal-Wallis 检验显著（p=2.5×10⁻⁷），说明未调整的组间差异主要来自混杂变量。消融实验显示朝向特征未带来预测精度增益，报告如实记录。项目交付本地 FastAPI 动态版与 GitHub Pages 静态版双形态前端，50 项测试全部通过。

**关键词**：二手房；房价预测；朝向溢价；数据预处理；特征工程；HistGradientBoosting

## 1 引言

### 1.1 背景与业务价值

购房者普遍关注朝向与采光，"南北通透""全南户型"是常见卖点。但直接比较各朝向均价会受到面积、区位、楼层等混杂因素影响：朝南房源往往同时位于更好的小区或更大面积，简单均价无法回答"朝向本身值多少钱"。本研究把其他因素控制住，估计朝向的边际溢价，并用完整预测模型验证朝向的增量价值。

### 1.2 研究问题

| 编号 | 问题 | 对应产出 |
|---|---|---|
| Q1 | 控制面积、房龄、楼层、区域后，不同朝向单价差异是否显著？ | 回归系数、95% CI、假设检验 |
| Q2 | 朝向溢价在不同区县是否一致？ | 分区县溢价表与异质性分析 |
| Q3 | 朝向加入预测模型带来多少增量价值？ | 消融实验 ΔR²、ΔRMSE |
| Q4 | 哪类房源对朝向更敏感？ | 分组误差与交叉特征探索 |

### 1.3 边界与纪律

观察性数据，不做因果断言；零结果如实报告；不采集个人隐私；不绕过登录、验证码与付费墙；数据仅用于课程学习。

## 3 数据预处理与特征工程（核心）

### 3.1 清洗流程与前后对比

`pipeline/clean.py`（`w2-v1`）流程：类型转换/文本清洗 → 单价重算 → 完全与业务去重 → 跨平台重复标记 → 区县补全 → 缺失值处理 → 别墅与异常值标记。各步骤行数见**表 1**。

| 步骤 | 输入 | 删除 | 修改 | 输出 |
|---|---:|---:|---:|---:|
| 读取 raw（按 source+url 去重） | 3326 | 0 | 0 | 3326 |
| 类型转换 / 文本清洗 | 3326 | 0 | 879 | 3326 |
| 朝向标准化 | 3326 | 0 | 13 | 3326 |
| 单价重算 | 3326 | 0 | 3220 | 3326 |
| 业务重复去重 | 3326 | 24 | 0 | 3302 |
| 跨平台重复标记 | 3302 | 0 | 5 | 3302 |
| 区县补全 | 3302 | 0 | 30 | 3302 |
| 缺失值处理 | 3302 | 0 | 11912 | 3302 |
| 别墅 / 异常值标记 | 3302 | 0 | 143 / 152 | 3302 |

**表 1** W2 清洗各步骤行数变化

### 3.2 缺失值与异常值

- 缺失策略：优先保留样本 + 显式"未知"类别 + 缺失标记，**禁止无依据 `dropna()` / `fillna(0)`**。朝向缺失 13 条设"未知"；建成年份缺 2636 条（`age_missing=1`）；装修缺 2513 条；楼层缺 930 条；电梯全缺，明确不入模。
- 异常值：按区县 IQR（样本 <50 回退全市）标记 152 条（4.60%），同时保留全市 3σ 对照；面积越界 5 条、总价越界 3 条。**只标记不删除**，建模阶段做"剔除 vs 保留"敏感性对比。
- 单价：`unit_price = total_price × 10000 / area`，原始挂牌价保留 `unit_price_raw`；偏差 >5% 的 43 条均为别墅/大平层（面积与花园/实用面积口径混用），标记 `unit_price_suspect=1`。
- 别墅/独栋标记 143 条，主样本保留，供敏感性对比。

### 3.3 特征工程

`pipeline/features.py`（`w3-v1`）以广州房天下 `model_keep=1` 的 1251 条为主样本，按区县分层 80/20 划分（seed 42）。

- 数值特征：area、log_area、rooms、halls、total_floors、floor_ratio、age（主样本全缺，剔除）、area_per_room、rooms_missing、floor_missing 等。
- 朝向衍生：is_south、is_south_north、orientation_count、orientation_missing、orientation_score（主观辅助）、south_ratio。
- 类别编码：district/orientation_main/building_type 用 One-Hot；floor_level/decoration 用有序编码；plate/community 用频次编码（不做 Target Encoding，避免泄漏）。电梯因全缺不入模。
- **防泄漏**：中位数、One-Hot 类别集合、频次表只在训练集 fit；测试集仅 transform，未见类别按 0 处理。训练集零方差列（bathrooms、age、age_missing、decoration_code）自动剔除，最终入模特征 40 个。
- **标准化**：线性/Ridge 模型在 Pipeline 内用 **Z-Score**（StandardScaler）标准化，使不同量纲特征对正则化惩罚公平；树模型不依赖标准化，保持原始尺度以保留可解释的分裂阈值。所有 fit 只在训练集进行。

## 4 模型构建与评估

### 4.1 基线与候选模型

基线：全局均值、区县均值、面积单变量线性回归；候选：Ridge、RandomForest、HistGradientBoosting。统一 Pipeline 封装，5 折 CV，网格/随机搜索**只在训练集**，测试集仅做最终评估。

### 4.2 评估结果

| 模型（测试集，元/㎡） | RMSE | MAE | R² |
|---|---:|---:|---:|
| 全局均值基线 | 27425 | 19882 | −0.096 |
| 区县均值基线 | 19019 | 12017 | 0.473 |
| 面积单变量基线 | 25483 | 17727 | 0.053 |
| Ridge | 16779 | 10505 | 0.590 |
| RandomForest | 14216 | 8723 | 0.705 |
| **HistGradientBoosting（最优）** | **14106** | **8834** | **0.710** |

**表 2** 模型测试集性能对比

最优模型 R²=0.710 ≥ 0.65；相对区县均值基线 RMSE 下降 25.8% ≥ 15%，两项验收达标。评估指标同时在 log 尺度与元/㎡尺度报告（含 MSE、RMSE、MAE、R²）。

### 4.3 朝向溢价分析

设定：`log(unit_price) = β0 + 朝向 dummy + log(area) + floor_ratio + rooms + 区县固定效应 + ε`，参照组"北"，HC3 稳健标准误，样本 1251 条，R²≈0.684。

| 朝向 | n | 溢价 | 95% CI | p |
|---|---:|---:|---:|---:|
| 北（参照） | 63 | 0 | — | — |
| 南 | 894 | +4.1% | [−5.4%, +14.4%] | 0.413 |
| 东南 | 143 | −0.4% | [−10.6%, +10.4%] | 0.945 |
| 东 | 46 | +19.7% | [+0.2%, +43.1%] | 0.048 |

**表 3** 主要朝向溢价估计（详见 `reports/orientation_premium.csv`）

- **Q1 结论**：控制混杂后朝南未发现显著溢价；1000 次 bootstrap 结论一致。原始分布 Kruskal-Wallis 显著（p=2.5×10⁻⁷），说明未调整差异来自混杂变量。
- **Q2 结论**：11 区中仅荔湾区朝南溢价显著为负（−32.7%，p=0.011），其余不显著；存在多重比较，仅作探索性解读。
- **Q3 结论（消融）**：A 无朝向 R²=0.5953 / B 含朝向 0.5936 / C 加交叉 0.5937；朝向未带来预测增益（ΔR²=−0.0017），如实报告"未发现增量价值"。
- **跨城市稳健性**：链家/贝壳 + 城市固定效应下朝南 −1.3%（p=0.80），方向与广州不一致且不显著，仅作方向性参考，不与主表混算。

### 4.4 敏感性分析

剔别墅/异常值后 Ridge 测试 RMSE 由 16698 降至 12862，说明别墅与异常值确实增加噪声；主模型 HistGB 在保留全部样本口径下仍达标，因此主口径保持"全保留 + 标记"。

### 4.5 全样本模型（数据量达标）

为验证组内建模数据量，另用全部 `model_keep=1` 的 **3297 条**记录（覆盖三站、34 城，含 city/source/district 固定效应，编码只在训练集 fit）训练模型：HistGB 测试 RMSE 12069 元/㎡、R² 0.695；Ridge RMSE 13943 元/㎡、R² 0.592。结果满足大纲"组内最终建模数据至少 2000 条"要求。广州房天下 1251 条仍是**主分析与朝向溢价表的唯一口径**，全样本模型只作数据量达标与稳健性检验。

### 4.6 特征选择与分析特征

用 permutation importance 与 Pearson 相关性矩阵（`reports/feature_correlation.csv`）做初步筛选；"区域均价偏离度"以 `reports/district_price_gap.csv` 输出为**分析特征**，不入模，避免把目标变换重复喂给模型造成泄漏。房龄因房天下列表页缺失、装修同理，未进入主模型，作为数据源局限性说明。
