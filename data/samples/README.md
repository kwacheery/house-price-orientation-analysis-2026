# 样本数据说明

本目录保存从 W1 原始数据中分层抽样的脱敏样本，用于课堂演示与代码复现。
原始数据在 `data/raw/`，按 `.gitignore` 不进入版本管理。

| 文件 | 来源 | 条数 | 抽样方式 |
|---|---|---:|---|
| `fang_sample.csv` | 房天下广州 | 60 | 按 11 区县分层 |
| `lianjia_sample.csv` | 链家多城市首页 | 60 | 按城市分层 |
| `beike_sample.csv` | 贝壳多城市首页 | 60 | 按城市分层 |

生成命令：

```bash
python scripts/make_samples.py
```

字段与 `docs/PLAN.md` 4.3 数据字典一致，不包含房东/经纪人姓名、电话、微信、身份证、门牌号等个人信息。
样本只用于课程学习，不用于商业用途，不再分发原始数据。
